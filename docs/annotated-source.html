Module-level state and the percentile — lines 115–133

131     k = (len(values) - 1) * (p / 100.0)
132     lo, hi = int(k), min(int(k) + 1, len(values) - 1)

One lazily-loaded encoder, shared by everything that needs to compare meaning.

The whole module

14 _model = None
17 def get_model():
19     global _model
20     if _model is None:
21         from sentence_transformers import SentenceTransformer
23         _model = SentenceTransformer(EMBEDDING_MODEL)
24     return _model
27 def embed(texts, normalize: bool = True) -> np.ndarray:
29     if isinstance(texts, str):
30         texts = [texts]
31     vecs = get_model().encode(list(texts), convert_to_numpy=True,
34         normalize_embeddings=normalize, show_progress_bar=False)
36     return np.asarray(vecs, dtype=np.float32)
39 @lru_cache(maxsize=4096)
40 def embed_one(text: str) -> tuple:
42     return tuple(float(x) for x in embed([text])[0])
45 def cosine(a, b) -> float:
49     na, nb = np.linalg.norm(a), np.linalg.norm(b)
50     if na == 0.0 or nb == 0.0:
51         return 0.0
52     return float(np.dot(a, b) / (na * nb))
  1. L14Module-level cache slot. Modules are executed once per process, so this survives across every call.
  2. L19global is required to rebind a module-level name inside a function. Without it, line 23 would create a local variable and the cache would never fill.
  3. L21The import is inside the function, not at the top. Importing sentence_transformers pulls in torch and costs seconds, so a module that only needs cosine() never pays for it.
  4. L29–30Ergonomics: a bare string would otherwise be iterated character by character, silently embedding each letter separately. This coerces it to a one-element list.
  5. L34The key argument. Scales every vector to length 1. Once vectors are unit-length, cosine similarity reduces to the plain dot product — which is why similarity code elsewhere is just mat @ q with no division.
  6. L36float32 rather than float64: half the memory, and the precision difference is irrelevant for similarity ranking.
  7. L39lru_cache memoises by argument. The same query embedded twice costs one forward pass.
  8. L42Returns a tuple, not an array, because lru_cache requires hashable values and numpy arrays are unhashable.
  9. L50–51Guard against divide-by-zero on an all-zero vector. Rare, but it turns a crash into a defensible 0.0.

llm.py

268 lines MOCK_LLM

One interface, two backends. The mock is deterministic, offline, and structurally unable to hallucinate.

Sentence splitting — the shared primitive

_SENT_SPLIT = re.compile(r"(?<=[.!?])\s+(?=[A-Z0-9])")

def split_sentences(text: str) -> List[str]:
    text = re.sub(r"^#.*$", "", text, flags=re.MULTILINE)  # drop headings
    text = re.sub(r"\s+", " ", text).strip()
    return [s.strip() for s in _SENT_SPLIT.split(text) if s.strip()]
  1. regexTwo zero-width assertions. (?<=[.!?]) means "preceded by sentence punctuation"; (?=[A-Z0-9]) means "followed by a capital or digit". The split happens on the whitespace between them, and because lookarounds consume nothing, no characters are lost.
  2. whyRequiring a following capital stops it splitting on abbreviations. The whitespace collapse on the next line means a newline mid-sentence does not create a phantom break.
  3. reuseUsed by the chunker, the mock generator, the groundedness check and the judge — one definition of "sentence" across the whole project.

MockLLM.generate_grounded — extractive answering

SENTENCE_FLOOR = 0.22
MAX_SENTENCES  = 3

def generate_grounded(self, question, contexts):
    sentences = []
    for c in contexts:
        for s in split_sentences(c):
            if s not in sentences:          # dedupe overlapping chunks
                sentences.append(s)

    q   = np.asarray(embed_one(question), dtype=np.float32)
    mat = embed(sentences)
    scored = sorted(((float(np.dot(q, mat[i])), sentences[i])
                     for i in range(len(sentences))), key=lambda t: -t[0])

    picked = [s for sc, s in scored[:self.MAX_SENTENCES] if sc >= self.SENTENCE_FLOOR]
    if not picked:
        return "I don't know."
    picked.sort(key=sentences.index)
    return " ".join(picked)
  1. dedupeSentence chunks overlap by design, so the same sentence arrives in two chunks. The not in check keeps the answer from repeating itself.
  2. np.dotPlain dot product — valid as cosine similarity only because embed() normalised the vectors. This is where that decision pays off.
  3. lambdakey=lambda t: -t[0] negates the score to sort descending. Sorting tuples would otherwise compare the sentence text on ties; negating the number keeps the intent obvious.
  4. floor0.22 is a low bar deliberately: retrieval has already filtered by the time we get here, so this only drops sentences swept in as chunk padding.
  5. sortpicked.sort(key=sentences.index) restores original reading order. Without it the answer would be ordered by relevance and read as disconnected fragments.
Why this cannot hallucinate

Every returned sentence came out of contexts. There is no code path that composes new text. That is a stronger guarantee than any prompt gives you with a real model — and it is why the whole project stays honest under mock mode.

MockLLM.judge_triad — the three axes

  1. cmat @ qMatrix times vector: one similarity per chunk in a single operation. np.max takes the best — "did retrieval find anything relevant".
  2. .TTranspose turns an (n_ctx, 384) matrix into (384, n_ctx) so the product is an (n_ans, n_ctx) grid: every answer sentence scored against every context sentence at once.
  3. axis=1Max along each row = "the best support this answer sentence has anywhere in the context". An answer sentence only needs one supporting source, not all of them.
  4. np.meanbest >= 0.60 is a boolean array; the mean of booleans is the fraction that are True. So groundedness is literally "what proportion of my sentences are supported".
  5. refusal → 1.0A refusal asserts no claim about hiring policy, so nothing in it can be unsupported. Vacuously grounded.
  6. 1.0 − ctxThe clever one. A refusal is correct exactly when there was nothing to work with. If good context existed, this scores near zero — so an over-refusing agent is punished by the metric.

What the measurement found

In-scope 0.62–0.81, out-of-scope 0.14–0.20 — a gap of roughly 0.43. The popular defaults (0.5, 0.6, 0.7) all sit inside the in-scope cluster, so they would have refused real, answerable questions. Guessing would have broken the agent in a way a happy-path demo would never have revealed.

The result refuses to be tidy

Sentence-based wins precision 0.80 vs 0.63; fixed-size wins recall 1.00 vs 0.80. Neither dominates. The recommendation argues that fixed-size only reaches perfect recall because its wide windows sweep in extra documents indiscriminately — the same behaviour that costs it precision — and picks sentence-based because a confidently wrong answer is the failure that actually hurts a recruiter.

tools.py

The second tool: look up one application and score how urgently a human should see it.

The formula

W_FLAG   = 0.60
W_AGE    = 0.40
DAYS_P80 = 23.0
ESCALATION_THRESHOLD = 0.40

def compute_escalation_score(flagged: bool, days_since_created: int) -> float:
    recency_norm = min(days_since_created / DAYS_P80, 1.0)
    score = W_FLAG * (1.0 if flagged else 0.0) + W_AGE * recency_norm
    return round(min(1.0, max(0.0, score)), 4)
  1. DAYS_P80Not invented — it is days_percentile(80) from the dataset. That is what makes this a designed score rather than a guessed one.
  2. min(…, 1.0)Saturates the age term. An application 30 days old and one 23 days old both score 1.0 on recency — past the 80th percentile, "older" stops carrying extra information.
  3. weights0.60 + 0.40 = 1.0, so the score is bounded in [0,1] by construction. The flag alone clears 0.60; age alone maxes at 0.40.
  4. min/maxBelt-and-braces clamp. Harmless today, but it means a future weight change cannot silently produce a score outside the schema's declared range.
  5. threshold0.40 is exactly what an unflagged application scores at 23 days. So the rule reads: escalate everything already flagged, plus the slowest-moving fifth of everything else.

  2. PYTHONIOENCODINGWindows consoles default to cp1252, which would mangle any non-ASCII character in a transcript.
  3. sys.executableThe current interpreter path, so subprocesses use the same virtualenv rather than whatever python resolves to on PATH.
  4. errors="replace"An undecodable byte becomes a replacement character instead of crashing the whole run at step 14.
  5. __reindex__The ordering detail. Step 11/12 adds a 13th document via /add-document. Without this re-index between them, the triad evaluation would score a different corpus than the one documented. Evaluation must run against a known, fixed knowledge base.
  6. isolationEach step is a fresh process, so a crash in one cannot corrupt another's state — and each pays the 20 s model load, which is why the full suite takes about 6 minutes.
